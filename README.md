# Phishing URL Detection

Командный проект курса «Основы ИИ в кибербезопасности» на тему обнаружения фишинговых сайтов по признакам URL.



## Цель

Классифицировать URL как легитимный или фишинговый на основе признаков самого URL и, при наличии разрешённых данных, признаков доменного имени.

## Структура

- `data/raw/` — исходные открытые или синтетические данные;
- `data/processed/` — очищенные и преобразованные данные;
- `notebooks/` — EDA, обучение и отчётные эксперименты;
- `src/` — переиспользуемый Python-код;
- `reports/` — отчёт 8–12 страниц и экспортируемые графики;
- `presentation/` — презентация и сценарий демо;
- `tests/` — тесты обработки URL и качества признаков.

## Безопасность

Проект выполняется только на открытых или синтетических данных. Adversarial-примеры создаются путём изменения URL в коде; никакие реальные системы и домены не атакуются.

> Используется реальный открытый датасет PhiUSIIL. Результаты получены на отложенной выборке 20%; seed = 42.

## Датасет

- Название: PhiUSIIL Phishing URL (Website);
- Источник: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+website);
- Лицензия: CC BY 4.0;
- Размер: 235 795 строк, 56 исходных столбцов;
- Метки: `1` — легитимный URL, `0` — фишинг;
- Распределение: 134 850 легитимных и 100 945 фишинговых URL;
- После удаления неинформативных текстовых столбцов используются 50 числовых признаков;
- Train/test: 188 636 / 47 159 с стратификацией.

Файл: `data/raw/PhiUSIIL_Phishing_URL_Dataset.csv`.

## Полученные метрики

Метрики Precision, Recall и F1 рассчитаны для класса фишинга (`label = 0`). Accuracy дана для обоих классов. Матрица ошибок приведена в порядке `[0=фишинг, 1=легитимный]`.

| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC | Матрица ошибок |
|---|---:|---:|---:|---:|---:|---|
| Logistic Regression | 0.999873 | 1.000000 | 0.999703 | 0.999851 | 1.000000 | [[20183, 6], [0, 26970]] |
| Random Forest | 1.000000 | 1.000000 | 1.000000 | 1.000000 | 1.000000 | [[20189, 0], [0, 26970]] |
| MLP | 0.999936 | 1.000000 | 0.999851 | 0.999926 | 1.000000 | [[20186, 3], [0, 26970]] |

Для Logistic Regression пропущено 6 фишинговых наблюдений; для MLP — 3. Random Forest не допустил ошибок на отложенной выборке.

Фактические данные сохранены в `reports/phiusiil_metrics.json` и `reports/model_metrics.csv`. Обученные модели сохраняются в `models/`.

Требуется проверить наличие утечки признаков: датасет содержит признаки страницы, текста заголовка и структуры HTML, а не только строку URL. Поэтому прежде чем сообщать о готовности к SOC, нужно повторно проверить временное разделение и сравнение с упрощённой моделью по признакам URL.
